## 1. 플랫폼 전략

### 1.1 모바일 우선 출시 → PC 후속 이식 [기획]

- **1차:** Google Play / App Store, **모바일 하이브리드 캐주얼 액션 RPG**.
  - 이유: 빠른 배경 구축, 엔드리스 파밍·성장 루프와 잘 맞음, 수익성이 가장 높음.
- **2차:** Steam(PC) **유료 패키지**로 이식 — 모바일에서 수익성·지표를 먼저 검증한 뒤.
  - 바로 동시 출시하지 않는 이유:
    - 스팀은 보상형 광고 BM을 쓸 수 없음
    - 화면 비율이 달라 UI·밸런스를 이중으로 만들어야 함
    - QA가 두 배

### 1.2 화면 규격: 세로(9:16) 전용 [기획]

- 한 손 조작을 최우선.
- 가로·세로를 함께 지원하면 생기는 문제를 원천 차단:
  - 전투 시야각이 달라져 밸런스가 깨짐
  - 인벤토리·상점 등 팝업 UI를 이중으로 제작 (시간·AI 토큰 2배)

> [확정 2026-11-28] 세로 고정. 게임 설정의 가로 전환 옵션은 제거했고, 가로는 스팀판에서 별도로 만듭니다.

## 3. 단계별 마케팅 · 퍼블리싱

### 3.1 1단계 — 초기 지표 검증 [기획]

| 항목 | 값 |
| --- | --- |
| 예산 | 약 **50만 ~ 150만 원** |
| 방식 | 소액 글로벌 광고 (설치당 단가 약 **0.5~1.5달러**) |
| 유입 목표 | **1,000~3,000명** |
| 합격 기준 | **D1 잔존율 35~40% 이상** |

실행 항목 [제안]:
- **측정 도구:** 분석 SDK(예: Firebase / GameAnalytics)와 광고 성과 측정(MMP) 연결. 출시 빌드에 반드시 포함.
- **함께 볼 지표:** D1 / D3 / D7 잔존, 첫 세션 길이, **첫 사망 지점**(몇 층), 튜토리얼 완료율, 광고 시청률, ARPDAU.
  - 이 게임은 "초반이 어렵다"가 의도이므로, 첫 사망 층과 이탈의 관계를 꼭 봅니다.
- **소재:** 장비 외형이 바뀌는 순간, 타격감(히트스톱·연속 타격), 리듬 판정 성공, 어두운 던전 속 청록 주인공 — 세로 15초 영상 3~5종.
- **테스트 국가:** 설치 단가가 낮은 영어권·동남아 일부 + 한국 소량 (언어 지원 범위에 따라) [미정].

### 3.2 2단계 — 자체 운영 또는 퍼블리셔 계약 [기획]

지표가 좋으면 둘 중 하나를 고릅니다.

| 선택 | 내용 |
| --- | --- |
| **자체 소규모 운영** | 월 **300만~500만 원**, 설치 단가가 낮은 국가 중심으로 확장 |
| **퍼블리셔 계약** | 검증된 지표로 하이브리드 캐주얼 전문 퍼블리셔와 계약, **마케팅비 전액 지원** |

퍼블리셔 후보 [기획]: Habby, Voodoo, Supersonic, 111% 등.

퍼블리셔에 가져갈 자료 [제안]:
- 1단계 지표 (D1/D7, 첫 세션, 광고 시청률, CPI)
- 게임플레이 영상
- 남은 콘텐츠 로드맵 (ACT·시즌)
- 운영 인력 계획

### 3.3 퍼블리셔 수익 배분 [기획]

마케팅비 전액 지원 기준, **순수익을 50 : 50 (또는 40 : 60)** 으로 나눕니다.

$$\text{순수익(Net Revenue)} = \text{총매출} - \text{스토어 수수료}(15\% \sim 30\%) - \text{마케팅 집행비(UA)}$$

예시 [제안 — 감 잡기용 가정치]:

| 항목 | 금액 |
| --- | --- |
| 총매출 | 1,000만 원 |
| 스토어 수수료 (15% 가정) | −150만 원 |
| 마케팅 집행비 (UA) | −500만 원 |
| **순수익** | **350만 원** |
| 개발사 몫 (50 : 50) | 175만 원 |
| 개발사 몫 (40 : 60, 개발사 40 가정) | 140만 원 |

> 스토어 수수료는 매출 규모·프로그램(중소 개발자 15%)에 따라 다릅니다. 40 : 60은 어느 쪽이 60인지 계약마다 다르니 확인이 필요합니다.
