# GDD 추가 사항 01 — 던전 구조 · 반출 제한 · 골드 소모 · 펫 · 레이드

`Docs/GDD.md`에 더해 2026-11-26에 확정된 방향과, 구현하면서 정한 기본 수치입니다.
수치는 모두 코드 한 곳(괄호 안 위치)에서 조정합니다.

## 1. 던전 구조: ACT → 던전 → 층

- ACT 5개 × 던전 3개 × 5층. 층의 몬스터를 **전부 처치해야 클리어** → 다음 층 (`Core/Dungeon/DungeonStructure.cs`).
- 몬스터는 무리 단위로 몰려오지만(동시 최대 16) **층 총수는 고정**이고 HUD에 `남은 몹 N / 총수`로 표시.
- 층당 몬스터 수는 ACT가 오를수록 증가 (10 → 100):

| ACT | 이름 | 층당 몬스터 |
| --- | --- | --- |
| 1 | 그림자 변경 | 10 → 20 |
| 2 | 잿빛 지하묘지 | 20 → 40 |
| 3 | 얼어붙은 심연 | 35 → 60 |
| 4 | 불타는 성채 | 55 → 80 |
| 5 | 공허의 왕좌 | 75 → 100 |

- 각 던전의 5층은 보스 층. 3층부터 정예 등장.
- 죽으면 **그 층에서 주운 전리품을 잃고** 층을 처음부터 다시 시작.

## 2. 반출 제한과 자동 판매 (폐지 = 돈)

- 층에서 주운 장비는 바로 가방에 들어가지 않고 "이번 층 전리품"에 쌓입니다.
- 층 클리어 시 **가져갈 장비 선택** 창: 한 층에서 **3개(보스 층 4개)**, 그리고 **가방 여유 칸**만큼만 가져감.
- 선택하지 않은 장비는 **자동 판매 → 골드**. 10초 동안 고르지 않으면 추천(가치순) 선택대로 자동 확정 (`DungeonRules`).
- 가방 크기 12칸 (`GameProfile.DefaultBagCapacity`). 가방에서도 판매 가능.

## 3. 골드 소모처

- **장비 강화** +0 ~ +15. 단계마다 모든 수치 +8%, 비용은 단계마다 1.32배 (`Economy/EnhancementService`).
- **성장 트리** 기본 3,000노드 (최대 10,000까지 생성 가능, `GameProfile.TreeSize`).
  - 14개 가지: 힘·생명 / 민첩·회피 / 지능·보호막 / 치명타 / 물리 방어 / 불 / 번개 / 얼음 / 대지 / 빛 / 어둠 / 골드·경험치 / 펫 / 전투 기술.
  - 이미 가진 노드와 연결된 노드만 구매. 비용 = 25 × (보유 수 + 1)^1.35 × 등급(일반 1 / 특급 3 / 핵심 8) → **살수록 계속 비싸짐**.
- **펫 성장** (아래).

## 4. 6속성

불 · 얼음 · 번개 · 대지 · 빛 · 어둠. 속성별 피해 % / 저항 %가 장비 옵션과 트리에 있습니다.
(기존 '비전'은 '빛'으로 통합, '빛의 마검격'. 대지 분쇄는 대지 속성.)

## 5. 펫

- 아주 작지만 꼭 필요한 보조 스킬을 쿨타임마다 자동 사용. 등급(★1~5)이 오르면 스킬 추가 개방.

| 펫 | ★1 | 추가 개방 |
| --- | --- | --- |
| 빛의 정령 | 보호막 걸기 | ★3 치유의 빛, ★5 원소 수호 |
| 호박 도깨비 | 신속 (이동·공격 속도) | ★2 고무 (피해), ★4 보호막 걸기 |
| 단단한 민달팽이 | 물리 피감 (방어도) | ★3 점액 재생, ★5 원소 수호 |

- 레벨업·등급업 모두 골드. 등급당 최대 레벨 10, 최대 레벨이어야 등급업 가능.

## 6. 4인 협동 레이드

- 하루 **3회** 입장 (자정 초기화). 제한 시간 **90초**.
- 보스 한 마리에 집중. **보스 체력은 처치할 때까지 입장 사이에 누적**되어 깎임.
- 보스 패턴은 바닥 **예고 범위**가 먼저 뜨고 일정 시간 뒤 발동: 대지 강타(원) · 어둠의 일섬(직선) · 화염 고리(보스 품이 안전 지대) · 운석 비 · 망령 소환. 체력 30% 이하 **격노**(패턴 가속, 피해 1.5배).
- 자동 전투도 예고 범위를 피해 움직임.
- 보상: 기여 피해 비례 골드, 처치 시 전설/세트 2개 + **막타 보너스**. 처치하면 다음 보스(레벨 +1, 3종 순환).
- 현재 동료 3명은 **AI**. 실제 온라인 4인 매칭은 `IRaidPartySource`를 네트워크 구현으로 교체하는 다음 단계.

> 참고한 '예전 별이되어라 레이드' 감각: 보스 체력 누적, 기여도 순위, 막타 보너스, 하루 입장 제한, 예고 패턴 회피를 반영했습니다.
> 기억과 다른 부분이 있으면 알려 주세요 (예: 보스 발견/공유 방식, 입장 재화, 파티 구성 규칙).

## 7. 저장

로컬 JSON (`Application.persistentDataPath/shadow_profile.json`): 골드, 가방, 장비(강화 포함), 레벨, 직업, 던전 진행, 트리, 펫, 레이드 상태.
`GameBootstrap > Reset Save On Start`로 새로 시작.
