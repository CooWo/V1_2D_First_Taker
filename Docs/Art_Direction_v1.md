## 1. 한 줄 정의

**"칠흑 같은 저주받은 던전 속, 차가운 청록빛을 두른 그림자 전사."**
굵은 검은 외곽선과 칼같이 떨어지는 명암의 코믹스풍 다크 판타지. 화면 대부분은 어둠이고, 빛은 **불타는 화염(따뜻한 주황)** 과 **청록 저주 룬·주인공(차가운 청록)** 두 가지만 이야기를 합니다.

## 1.1 핵심 게임 컨셉 [확정]

다크 판타지 세계관 기반의 모바일 세로형 액션 RPG. 저주받은 던전의 층을 돌파하며 장비를 파밍하고, **실시간으로 외형이 바뀌는 무기·방어구**를 조합해 캐릭터를 끝없이 성장시킨다. 메인 던전 외에 보스 러시, 장비 합성·강화, 채널 기반 마을 소셜 허브 같은 직관적인 부가 콘텐츠로 장기 잔존을 노린다.

> 던전 구조 [확정 2026-11-28]: ACT별 던전(4~6개 × 10층)을 따라 최종 콘텐츠에 도달하면 그때부터 **엔드리스 던전**(엔드게임). 보스 러시는 신규 모드, **장비 합성은 출시 초기부터** 포함. 아트는 **ACT 1부터** 완성도·통일성을 잡고 확장합니다.

## 2. 레퍼런스와 "어두운 던전"의 정확한 뜻

### 2.1 레퍼런스 [확정]

| 레퍼런스 | 가져올 것 | 가져오지 않을 것 |
| --- | --- | --- |
| **Curse of the Dead Gods** | 묵직한 코믹스풍 조형, 굵은 검은 외곽선, 2~3단 셀 셰이딩, 강한 명암 대비, 어둠 속 화염 광원 | 캐릭터·몬스터·문양·UI 등 구체적 디자인 일체 |
| **Darkest Dungeon** | 고딕 공포 분위기, 잉크처럼 짙은 그림자, 채도를 누른 좁은 팔레트, **횃불 빛이 곧 안전**이라는 감각, 낡고 습한 석조 | 횡스크롤 구도, 캐릭터 디자인, 스트레스 연출 그림 |
| **Diablo 2** | 위에서 내려다보는 던전, **캐릭터 주변만 밝고 화면 가장자리는 거의 검정**, 흙·돌·피의 무거운 색, 좁고 숨 막히는 지하 공간, 장비가 그대로 외형이 되는 쾌감 | UI·아이템 아이콘·몬스터 디자인 그대로 |

**저작권 원칙 [확정]:** 레퍼런스는 분위기·원리만 참고하고, 모든 형태·문양·색 조합은 100% 오리지널로 만든다. 특정 게임의 캐릭터·몬스터·로고·UI를 "비슷하게 바꾼" 것도 금지.

### 2.2 "어두운 던전" = 무엇이 어두운가 [확정 + 제안 수치]

어둡다는 것은 **화면 전체 밝기를 낮추는 것이 아니라**, 어둠과 빛의 **면적 비율과 대비**로 만든다. (`Direction_v1.md` §10: 어두움은 에셋으로)

| 원칙 | 구체적 기준 [제안] |
| --- | --- |
| **어둠이 화면의 대부분** | 던전 화면의 **60~70%** 가 명도 15% 이하 (거의 검정·짙은 남색). 벽 너머는 완전한 공허 |
| **빛은 섬처럼** | 밝은 곳은 ① 주인공 주변 원형 시야 ② 횃불·화로 ③ 청록 룬 ④ 전투 이펙트뿐. 빛 웅덩이 사이는 반드시 어둠으로 끊김 |
| **빛 = 안전, 어둠 = 위협** | 몬스터는 어둠 속에서 실루엣·발광 눈으로 먼저 보이고, 빛 안으로 들어올 때 디테일이 보인다 |
| **채도는 낮게, 강조색만 높게** | 돌·흙·나무·뼈는 채도 15~30%. 높은 채도는 화염 주황·청록·피·아이템 등급색에만 |
| **바닥은 어둡게, 캐릭터는 읽히게** | 바닥 명도 < 캐릭터 명도. 캐릭터는 외곽선 + 림라이트로 어둠에서 분리 |
| **습하고 낡음** | 금 간 돌, 이끼, 녹, 피얼룩, 뼈, 거미줄, 촛농. 깨끗하고 새것 같은 표면 금지 |
| **만화적 귀여움 금지** | 2~3등신 치비 비율, 파스텔, 둥글고 매끈한 장난감 형태 금지 (§13: 현재 임시 에셋 문제) |

**한눈에 판별하는 방법:** 게임 화면을 흑백으로 바꿨을 때 ① 대부분이 검고 ② 주인공·적·빛 덩어리만 하얗게 남으면 합격.

## 3. 시각 시그니처 [확정]

1. **굵고 선명한 검은 외곽선** — 모든 캐릭터·몬스터·소품·장비. 바닥 타일과 벽 반복면만 예외.
2. **2~3단 셀 셰이딩** — 밝음 / 중간 / 그림자가 칼같이 나뉨. 부드러운 그라데이션 금지 (림라이트·발광 제외).
3. **칠흑의 어둠 + 두 가지 광원** — 불타는 화염(따뜻함, 안전·위험) 과 차가운 청록 저주 룬·주인공(차가움, 저주·힘).
4. **주인공 = 차가운 청록(Cyan)** — §5.

## 5. 메인 캐릭터 — 그림자 전사 (청록 통일감)

### 5.1 컨셉 [확정]
- **그림자 전사 = 주인공의 기본 컨셉.** 직업은 패시브(직업 전용 트리)를 더할 뿐 외형 정체성은 같다. 스킬은 장비에서 오므로 **외형은 장비가 바꾼다** (직업이 아니라).
- 어두운 무술복·튜닉, 팔다리 **압박 붕대**, **강렬하게 빛나는 눈**, 검은 **그림자 불꽃 아우라**.
- **차가운 청록(Cyan)이 주인공의 통일 요소.** (기존 시트의 "푸른 눈"은 청록으로 맞춤)

### 5.2 청록 통일 규칙 [제안]
장비를 무엇으로 바꿔도 주인공이 "그 캐릭터"로 보이게 하는 고정 요소입니다.

| 고정 요소 | 규칙 |
| --- | --- |
| **눈** | 항상 얼음 청록 `#5CF2FF` 발광. 투구를 써도 눈 구멍으로 보임 |
| **그림자 불꽃 아우라** | 검은 불꽃, 가장자리만 청록. 발밑·어깨에서 피어오름 |
| **붕대** | 팔·다리 붕대는 어떤 방어구 아래서도 일부 보임 (손목·발목) |
| **청록 포인트 면적** | 캐릭터 실루엣의 **5~10%** 만 청록. 나머지는 어두운 무채색·가죽·철 |
| **장비의 청록** | 주인공이 착용한 무기·방어구의 룬·문양·날 끝은 **청록으로 발광** (같은 장비라도 적이 들면 주황·핏빛) |
| **스킬·타격 이펙트** | 주인공 이펙트의 주색은 청록 + 흰 중심. 속성 스킬(불·번개 등)도 가장자리에 청록 잔광 |
| **림라이트** | 주인공 뒤쪽 테두리 빛은 청록 (굽기 설정 `rimColor`) |

### 5.3 실루엣 [제안]
- 비율: **5~6등신** (현재 임시 KayKit 모델은 2.5등신 치비 → 교체 대상).
- 화면에서 캐릭터 키 ≈ 화면 가로의 **12~14%** (현재 카메라 기준 약 1.3칸).
- 검정으로 칠해도 무기 종류·자세가 읽혀야 함 (무기는 실루엣 밖으로 크게).

### 5.4 기제작 시트 [확정]
- 3D 변환 전용 정면 A-포즈 단독 시트 (단색 회색 배경, 연기 파편·격자 제거) 완료.

## 7. 환경

### 7.1 1액트 던전 — 저주받은 지하 석조 던전 [확정 + 제안]
- 키트 (원화 완료 8종 + 화로): 균열 암석 바닥 타일, **청록 발광 룬 바닥 타일**, 모듈형 낮은 석조 벽, 가고일 부조 파괴된 기둥, 저주받은 룬 제단, 철제 장식 보물상자, 파괴 가능한 고대 항아리 2종, 화로(불꽃 제거 베이스).
- 구도: 방 + 좁은 통로, 화면 대부분 공허 (§2.2).
- 빛 배치 [제안]: 방 하나에 화로·횃불 1~2개 + 청록 룬 바닥 0~3칸. 통로는 빛 없음 (주인공 시야만).
- 벽은 **낮은 석조 벽**: 3/4 시점에서 벽이 바닥을 가리지 않게.

### 7.2 1액트 시작 마을 — 안개 낀 밤 고목 숲 생존자 야영지 [확정]
던전(차가운 석조)과 명확히 대비되는 **숲·나무·불** 공간.

| 구역 (세로 2화면) | 내용 |
| --- | --- |
| 하단 (최초 스폰) | 연철 가로등이 밝힌 숲길 진입로 |
| 중앙 (소셜 광장) | 거대한 돌 테두리 **모닥불**, 통나무 벤치, 원형 강돌 자갈 광장 |
| 상단 (기능 거점) | 좌: 목조 슬레이트 지붕 **대장간** (강화·합성) / 우: 방랑 상인 **천막 마차** (상점·교환) |

- 던전 입구 구조물 없음: UI 버튼으로 바로 전투 진입.
- 한 공간에 **10~20명**이 보이는 채널·위상 구조 (장비 외형 과시).
- 최적화: 바닥은 **평면 텍스처 1장**, 외곽은 **밤안개**로 감쌈.
- 기제작 [확정]: 마을 배치도, 모닥불 화덕·장작 베이스, 모루 포함 목조 대장간, 천막 상인 마차, 통나무 벤치 + 연철 가로등 세트.
- 마을 색 [제안]: 숲·안개는 짙은 청회색, 중심 빛은 **모닥불 주황**. 청록은 주인공·다른 플레이어에게서만.

## 9. 장비 외형 (실시간 외형 변화) [확정 방향 + 제안]

- 무기·방어구를 바꾸면 화면 캐릭터 외형이 바뀐다 (핵심 재미).
- 외형 단위 [확정]: **무기 · 투구 · 갑옷 · 망토** 4부위. 4부위 모두 화면 외형에 반영 (현재 구현은 무기 종류만 → 굽기 구조 확장 필요).
- 제작 방식 [제안]: 몸 + 4부위를 각각 3D로 만들고, 굽기 단계에서 조합을 구움. 조합 수가 커지면 "부위별 레이어 스프라이트"로 나눠 굽는 방식을 검토 (§13.2).
- 같은 종류 안의 등급 차이는 **문양·발광 양**으로 (일반 = 발광 없음, 전설 = 청록 룬 발광 + 작은 입자).
- 외형마다 굽기 설명서 하나 (`Assets/_Game/Art/Bake/Specs/Char_*.asset`), 키 규칙 `클래스/무기외형`.

### 15.3 결정 (2026-11-28)
1. **시점 = 아이소메트릭** (확정). 게임 지도·정렬·카메라·굽기를 아이소메트릭으로 바꿈. 게임 규칙(격자)은 그대로.
2. **적의 청록 금지** (확정). 1액트 몬스터 원화는 **누더기 형태 + 빛바랜 어두운 색**으로 다시 그림 (눈·룬 발광은 주황·핏빛·병든 녹색). 게임 안 임시 몬스터도 어둡게·청록 없이 굽기.
3. **어둡게 만드는 우선순위** (확정): ① 그림자 면을 거의 검정까지 ② 돌·나무 채도를 낮추고 때·그을음·핏자국 ③ 큰 덩어리와 실루엣 우선 (작은 문양은 나중).
3. **AI 이미지 워터마크.** 원화 우하단의 생성 도구 표시(✦)는 게임 에셋에 들어가지 않도록 잘라 냄. 사용한 도구의 상업 이용 조건을 확인해 두기.

### 15.5 외부 도구 후보 (이미지 → 3D → 움직임) [제안 — 선택 필요]
