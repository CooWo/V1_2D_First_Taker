# [Master GDD & AI Spec] 2D 도트 액션 RPG: 장비 내장형 스킬 & 9슬롯 빌드 시스템

본 문서는 **검은 그림자 아지랑이 베이스의 2D 도트 캐릭터**를 중심으로, **디아블로3(Diablo 3)의 직관적인 세트·전설 장비 파밍 체계**와 **패스 오브 엑자일(Path of Exile, 이하 PoE)의 무직업 스탯·태그 기반 스킬 빌드 시스템**을 결합하고, 모바일 **자동 사냥(Auto-Battle)** 환경에 최적화한 통합 기획 및 개발 AI 전달용 마스터 명세서입니다.

## 1. 코어 시스템 철학: D3 장비 $\times$ PoE 스킬 하이브리드

### 1.1 캐릭터 및 직업(Class)의 재정의: "스킬 제한 없는 전직 특화"
* **기본 베이스**: 모든 플레이어는 무채색 초보자 의상과 푸른 안광, 온몸에 검은 그림자 아지랑이가 피어오르는 동일한 그림자 인간형 캐릭터로 시작합니다.
* **무직업 스킬 개방**: 특정 직업만 특정 스킬이나 무기를 독점하지 않습니다. **장비에 내장된 스킬은 요구 능력치(힘/민첩/지능) 조건만 충족하면 누구나 장착하고 사용할 수 있습니다.** (예: 중갑을 입은 기사가 지팡이를 들고 운석 낙하를 시전하거나, 마법사가 쌍수 전투 장갑을 끼고 근접 치명타 시 주문 자동 발동 빌드를 구축 가능)
* **직업의 역할 (PoE '전직/Ascendancy' 모델)**: **기사, 마법사, 궁수, 수도사** 4개 직업은 스킬 해금 수단이 아니라 **고유 패시브 트리와 특정 빌드 메커니즘의 극대화(최적화)**를 위해 존재합니다.

| 직업 구분 | 주력 친화 스탯 | PoE식 전직 패시브 방향성 (빌드 최적화 역할) | 대표 시너지 빌드 예시 |
| :--- | :--- | :--- | :--- |
| **기사 (Knight)** | 힘 (STR) 중심 | 막기 확률 극대화, 방어도 비례 피해 증폭, 피격/막기 시 반격 트리거, 근접 피해 감소(Fortify) 효율 강화 | 방패 반격 오토 빌드, 초고방어 소용돌이(휠윈드) 탱딜 빌드 |
| **마법사 (Mage)** | 지능 (INT) 중심 | 원소 상태이상(점화/빙결/감전) 확산, 범위(AoE) 확장, 최대 마나 및 보호막 전환, 주문 재사용 대기시간 단축 | 화면 전체 연쇄 번개 빌드, 블랙홀+운석 자동 폭격 빌드 |
| **궁수 (Archer)** | 민첩 (DEX) 중심 | `[투사체]` 개수 $+1 \sim +2$ 추가, 관통/연쇄 보너스, 이동 속도 비례 공격력 증가, 거리 비례 피해 증폭 | 다중 회오리 사격 빌드, 부메랑 환영 무기 투척 빌드 |
| **수도사 (Monk)** | 민첩·힘·지능 복합 | 쌍수(양손 전투 장갑 등) 공격 속도 대폭 증폭, 치명타 확률/피해 한계 돌파, 그림자 분신 협공 및 치명타 트리거(CoC) 최적화 | 점멸 타격(플리커) 초고속 맵핑 빌드, 쌍수 장갑 치명타 주문 폭주(CoC) 빌드 |

### 1.2 3대 핵심 능력치 (힘 / 민첩 / 지능 통합 체계)
기존 직업별 개별 스탯을 PoE 방식의 **3대 코어 스탯**으로 일원화하여 모든 장비 착용과 스킬 계수의 기준점으로 삼습니다.

1. **힘 (STR / 적색 태그)**
   * $10$ 포인트당: 최대 생명력 $+50$, `[근접]` 및 물리 피해 $+2\%$, 기본 방어도 효율 $+1\%$ 증가
2. **민첩 (DEX / 녹색 태그)**
   * $10$ 포인트당: 공격 및 시전 속도 $+0.5\%$, 치명타 적중 보정 $+1\%$, 회피율 및 이동 반응성 증가
3. **지능 (INT / 청색 태그)**
   * $10$ 포인트당: 최대 자원(마나/기력) $+20$ 및 재생 증가, 에너지 보호막(실드) $+2\%$, `[주문]` 및 모든 원소 피해 $+2\%$ 증가

## 2. 9슬롯 장비 체계 및 장비 내장형 스킬 구조

### 2.1 9슬롯 기본 능력치 및 스킬 역할 분담
총 9개의 장비 슬롯 중 **무기 및 방어구(5칸)는 액티브/반응형 내장 스킬을 제공**하며, **장신구 및 특수 장비칸(4칸)은 PoE의 '보조 젬(Support Gem)' 및 '메타 트리거' 역할**을 수행하여 자동 사냥 시 스킬 슬롯 과포화와 쿨타임 꼬임을 방지합니다.

| 장비 부위 | 고정 베이스 | 주 속성 풀 (Primary) | 내장 스킬 / 보조 역할 (PoE 결합 규칙) |
| :--- | :--- | :--- | :--- |
| **오른손** *(주무기)* | 무기 공격력, 초당 공격 횟수 | 무기 피해(%), 속성 추가 피해, 스탯, 공격 속도, 적중 시 회복 | **[주력 액티브 스킬 슬롯 1]** 빌드의 핵심 딜링 스킬 내장 (한손검, 대검, 마법봉, 지팡이, 활, 우측 격투 장갑 등) |
| **왼손** *(보조/쌍수)* | 막기 확률(방패) / 공속(화살통) / 추가 피해(마력원) / 무기 공격력(좌측 장갑·쌍수) | 치명타 확률, 쿨타임 감소, 자원 소모 감소, 태그 스킬 피해(%) | **[주력 액티브 스킬 슬롯 2 또는 보조 오라]** 두 번째 주력 스킬, 연계기, 혹은 상시 발동 전령/오라 스킬 내장 *(양손 활+화살통 허용, 수도사형 격투 장갑은 좌·우 쌍수 장착 가능)* |
| **머리** | 기본 방어도 / 보호막 | 스탯, 생명력, **치명타 확률**, **쿨타임 감소**, 최대 자원량 | **[전술/버프/표식 스킬 슬롯]** 함성, 자동 저주/표식, 상시 버프 등 전투 보조 스킬 내장 |
| **몸** | **최상급 방어도 / 보호막** *(공격 옵션 배제)* | 스탯, 높은 생명력, **생명력 %**, **모든 속성 저항**, 정예 피해 감소 | **[생존/피격 반응 스킬 슬롯]** 보호막 전개, 피격 시 반격, 무적/흡수 등 자동 생존기 내장 |
| **신발** | 기본 방어도 + **기본 이동 속도** | 스탯, 생명력, 추가 이동 속도, 속성 저항, 이동기 쿨타임 감소 | **[기동/추적/회피 스킬 슬롯]** 돌진, 점멸, 연막 질주 등 자동 사냥 포지셔닝 스킬 내장 |
| **목걸이** | 모든 속성 저항(소량) | **속성 피해 증가(%)**, **치명타 피해(최대치)**, **치명타 확률**, 스탯 | **[보조 변환 슬롯]** 액티브 스킬을 늘리는 대신, 보유 스킬의 `[태그]`를 감지해 투사체 추가·연쇄·속성 변환 등 PoE식 **보조(Support) 효과** 부여 |
| **반지 1·2** *(2슬롯)* | 고정 추가 피해(소량) | **치명타 확률**, **치명타 피해**, **공격 속도**, **쿨타임 감소**, 자원 소모 감소 | **[보조 증폭 & 2세트 슬롯]** 특정 태그 스킬의 자원 순환 보정 및 조건부 딜 증폭 고유 권능 부여 |
| **특수 장비칸** *(성물/코어)* | 일반 공/방 수치 없음 | 고정 특수 옵션 1~2줄 (보스 추가 피해, 최종 자원 효율 등) | **[메타 트리거 & 규칙 파괴 슬롯]** 세트 요구 개수 $-1$ 감소, `치명타 시 시전(CoC)` 해금, `물리->원소 100% 전환` 등 빌드의 근간을 바꾸는 코어 장치 |

### 2.2 세트 장비 구조 (`2 / 3 / 4 세트` 체계)
* **메인 세트 구성 부위**: `머리 + 몸 + 신발 + 목걸이` (4부위 고정). 오른손·왼손·반지 2개·특수 장비칸(총 5칸)을 비워두어 내장 스킬 무기와 전설 시너지를 자유롭게 교체할 수 있도록 보장합니다.
* **세트 설계 주의사항 (무직업 호환성)**: 세트 효과는 특정 직업 전용이 아니라 **특정 스킬 원형** 또는 **특정 스킬 `[태그]` 조합**(예: `[근접] + [범위]` 스킬, `[지능] + [연쇄]` 주문)을 강화·변주하도록 설계합니다.

## 3. 스킬 등급 체계 (일반 $\rightarrow$ 마법 $\rightarrow$ 희귀 $\rightarrow$ 전설)

장비에 붙어 나오는 내장 스킬은 장비와는 별개(혹은 장비 등급에 연동)로 **일반 $\rightarrow$ 마법 $\rightarrow$ 희귀 $\rightarrow$ 전설**의 4단계 스킬 등급을 가집니다. 등급이 오를수록 단순 수치만 오르는 것이 아니라 **자동 사냥 편의성과 PoE식 메커니즘 진화(각성)**가 일어납니다.

| 스킬 등급 | 색상 코드 | 기본 계수 배율 | 등급별 핵심 해금 요소 및 메커니즘 변화 |
| :--- | :--- | :--- | :--- |
| **일반 (Normal)** | 백색 | $1.0\times$ (기준치) | 스킬의 순수 원형 작동. 기본 사거리 및 단순 쿨타임 기반 자동 시전 |
| **마법 (Magic)** | 청색 | $1.15\times$ | **수치 효율 개선**: 자원 소모량 $-15\%$ 감소 또는 재사용 대기시간 $-10\%$ 단축 + 스마트 타겟팅(체력 낮은 적/밀집 지역 우선 조준) 보정 |
| **희귀 (Rare)** | 황색 | $1.35\times$ | **보조 기믹 1종 내장**: 관통 $+1$회, 범위 $+20\%$ 확대, 스킬 충전 횟수 $+1$회, 또는 확정 상태이상(출혈/감전/둔화) 부여 |
| **전설 (Legendary)** | 주황색 | $1.65\times$ 이상 | **메커니즘 각성 (PoE 변형/각성 젬 포지션)**: 스킬의 형태나 발동 조건이 진화함 (예: 직선 발사가 $360^\circ$ 노바로 확장, 그림자 잔상 2연속 시전, 처치 시 쿨타임 즉시 초기화 등) |

## 4. 자동 사냥(Auto-Battle) AI 규칙 및 근·원거리 밸런싱 법칙

직업 제한 없이 누구나 원거리 스킬을 쓸 수 있는 자동 사냥 게임에서는, 그대로 두면 **접근 시간이 필요 없고 피격 위험이 적은 원거리 빌드가 근거리 빌드를 완전히 도태**시킵니다. 이를 시스템 레벨에서 해결하기 위해 다음 **5대 대칭 밸런싱 법칙**을 강제 적용합니다.

### 4.1 근거리 vs 원거리 5대 시스템 밸런싱 법칙

1. **선천적 근접 피해 감소 버프 — '그림자 갑주 (Shadow Fortify)'**
   * `[근접]` 태그가 붙은 직접 타격 스킬로 적을 명중시키면 캐릭터는 즉시 $4$초간 **그림자 갑주** 상태를 획득합니다.
   * 효과: 받는 모든 피해 $30\%$ 최종 곱연산 감소 및 피격 경직(넉백/히트스톱) 면역.
   * 제한: `[원거리]` 태그 스킬로는 절대 발동되지 않으며, `[원거리]` 스킬을 시전하는 순간 남은 지속시간이 절반으로 빠르게 소멸하여 원거리 빌드의 근접 유틸 악용을 차단합니다.

2. **자동 사냥 이동 딜로스 제거 — '그림자 추적 (Auto-Shadow Step)'**
   * 모든 `[근접]` 주력 스킬은 자동 사냥 중 반경 $3.5\text{m}$ 이내에 적이 있고 타격 범위에 닿지 않을 때, 느리게 걸어가지 않고 **검은 아지랑이 반동으로 즉시 파고드는 초단거리 대시 프레임($0.15$초)**을 기본 내장합니다. 이로써 자동 사냥 시 근접 캐릭터의 허공 이동 시간(딜로스)을 원거리 수준으로 압축합니다.

3. **기본 계수 및 유지력(Sustain) 비대칭 수식**
   * 동일 스킬 등급 및 동일 투자 스탯 대비 최종 피해 계수와 적중 시 회복 효율에 명확한 격차를 둡니다.
   $$D_{\text{Melee}} = D_{\text{Base}} \times 1.40, \qquad D_{\text{Ranged}} = D_{\text{Base}} \times 1.00$$
   $$H_{\text{Melee (적중 시 회복 효율)}} = 100\%, \qquad H_{\text{Ranged (다중 투사체 회복 효율)}} = 45\%$$

4. **광역 처리 방식의 등가 교환 (Splash vs Pierce)**
   * `[근접]` 스킬은 별도 옵션 없이도 전방 베기/충격파 형태의 **기본 다수 타격(Splash)** 판정을 가집니다.
   * 반면 `[원거리]` `[투사체]` 스킬은 기본적으로 **최전열 몬스터 1체 적중 시 소멸**하므로, 다수전 효율을 내려면 반드시 장비나 보조 슬롯에서 `[관통]`, `[연쇄]`, `[다중 투사체]` 옵션을 확보해야만 화면 클리어가 완성되도록 기회비용을 부과합니다.

5. **영거리 포위 리스크와 기동 쿨타임**
   * 원거리 스킬 사용 중 근접 몬스터에게 영거리($1.5\text{m}$ 이내) 진입을 허용하면 시전 후딜레이 중 피격 위험이 급증하며, 탈출용 신발 이동기 쿨타임 관리가 생존의 핵심이 됩니다.

### 4.2 자동 사냥 AI 발동 우선순위 큐 (Auto-Cast Priority Queue)
자동 사냥 루프는 매 $0.1$초마다 아래 우선순위($1 \rightarrow 6$)를 검사하여 스킬 꼬임 없이 최적의 전투 사이클을 수행합니다.

1. **1순위 `[상시 오라 / 패시브 트리거]`**: 전투 진입 시 자동 활성화 (재시전 불필요, 최대 자원 일부 점유 또는 쿨타임 자동 발동)
2. **2순위 `[생존 반응기 (몸 슬롯)]`**: 현재 생명력 $\le 50\%$ 이거나 보호막 파괴 시 최우선 즉시 발동
3. **3순위 `[회피 / 포지셔닝 이동기 (신발 슬롯)]`**:
   * 주력기가 `[원거리]`일 때: 반경 $1.5\text{m}$ 내 적 2체 이상 접근 시 안전 거리로 자동 이탈 질주
   * 주력기가 `[근접]`일 때: 반경 $4\text{m}$ 밖의 다음 몬스터 무리 중심으로 자동 돌진 진입
4. **4순위 `[전술 버프 / 표식기 (머리 슬롯)]`**: 정예/보스 몬스터 감지 시 또는 버프 만료 시 자동 갱신
5. **5순위 `[고화력 쿨타임 / 조건부 폭발기]`**: 재사용 대기시간이 돌아왔거나 특정 중첩(예: 독 5중첩, 충전 최대치) 달성 시 발동
6. **6순위 `[주력 자원 소모기 & 기본 공격기 (오른손/왼손)]`**: 자원 보유 시 주력기 연속 사용, 자원 부족 시 기본 평타/자원 생성기로 즉시 전환

### 5.4 장신구 & 특수 장비칸 전용: 메타 보조(Support) / 트리거 권능 (6종)
> PoE의 **보조 젬(Support Gem)**을 모바일 9슬롯 장비에 맞게 이식한 시스템입니다. 액티브 스킬 버튼을 늘리지 않으면서 보유한 스킬들의 작동 방식을 극적으로 결합합니다.

| 코드 | 보조/트리거 권능명 | 주요 부여 부위 | 연동 대상 태그 | PoE 기반 메커니즘 상세 효과 |
| :--- | :--- | :--- | :--- | :--- |
| `SUP-01` | **치명타 시 주문 시전 (CoC)** | 특수 장비칸 / 목걸이 | `[공격]` $\rightarrow$ `[주문]` | `[공격]` 태그 스킬이 치명타로 적중할 때마다, 장착 장비에 보유한 `[주문]` 태그 스킬 1개를 대상 위치에 자동 발동 (내부 쿨타임 $0.25$초, 발동 주문 피해량 $80\%$ 적용) |
| `SUP-02` | **피격 시 자동 시전 (CwDT)** | 몸 / 특수 장비칸 | `[생존]`, `[범위]`, `[주문]` | 누적 피격 피해량이 최대 생명력의 $25\%$에 도달할 때마다 쿨타임을 무시하고 연결된 방어기 또는 범위 스킬을 즉시 무료 발동 |
| `SUP-03` | **다중 투사체 분할 (GMP)** | 왼손 / 목걸이 / 반지 | `[투사체]` 전체 | 모든 `[투사체]` 태그 스킬(힘 투창, 민첩 화살, 지능 마법구 모두 포함)의 **동시 발사체 수 $+2 \sim +4$개 추가** (단일 투사체 피해량 $0.75\times$ 보정, 부채꼴 각도 자동 분배) |
| `SUP-04` | **그림자 메아리 (Shadow Echo)** | 특수 장비칸 / 왼손 | `[공격]` 또는 `[주문]` | 주력 스킬 시전 시 캐릭터 자리에 검은 아지랑이 잔상이 $0.25$초간 남아, **동일한 스킬을 자원 소모 없이 1회 반복 시전** |
| `SUP-05` | **연쇄 및 갈래 분열 (Chain & Fork)** | 목걸이 / 반지 | `[투사체]`, `[연쇄]` | 투사체가 첫 적을 맞힌 뒤 소멸하지 않고 두 갈래로 쪼개지거나(Fork) 주변 다른 적에게 $+2$회 자동 튕김(Chain) |
| `SUP-06` | **원소/심연 완전 전환 (Conversion)** | 특수 장비칸 / 반지 | `[물리]` $\rightarrow$ `[원소/암흑]` | 모든 스킬의 기본 물리 피해를 $100\%$ 특정 속성(화염/냉기/번개/암흑 중 택1)으로 강제 변환하여 세트 장비의 속성 증폭과 완벽히 일치시킴 |
