# 메뉴 구조 초안 v2

> 상태: **초안 (검토용)**. 기준 문서: `Direction_v1.md`, `Balance_Draft_v1.md`.
> 표기: **[기획]** = 합의된 기획 / **[제안]** = 제가 채운 항목 (검토 후 조정) / **[미정]** = 결정 필요.
> v2 변경: 던전 내 판매, 배속, 사망 원인 요약, 하단 바 / 전체 메뉴 구분, 일일 퀘스트·출석, 상점 구성.

## 0. 원칙

- **마을이 허브.** 성장·보관·입장 메뉴는 마을에서 연다.
- **던전 안은 최소 메뉴.** 장비는 보기만 (장착 불가). 가방은 정리·버리기(= 자동 판매) 가능.
- 모든 아이템 표기에 **전투력**과 **현재 장비 대비 증감**.
- 깊이는 최대 3단계 (메뉴 → 화면 → 팝업).

## 1. 메뉴 배치: 하단 바 vs 전체 메뉴

자주 쓰는 것은 **하단 메인 바**에, 나머지는 **전체 메뉴 창**(☰ 버튼)에 둔다.

### 1-1. 마을 하단 메인 바 (5개) [제안]

| 버튼 | 이유 |
| --- | --- |
| 캐릭터 | 장비·세팅 슬롯·스탯 — 가장 자주 확인 |
| 가방 | 귀환 후 바로 정리·장착 |
| 성장 | 단련·트리·강화·펫 — 골드 소모처 |
| 던전 | 핵심 루프 진입 |
| ☰ 전체 메뉴 | 나머지 전부 |

### 1-2. 전체 메뉴 창 [제안]

| 묶음 | 메뉴 |
| --- | --- |
| 콘텐츠 | 레이드 · PvP · 길드 |
| 성장 기록 | 도감 · 퀘스트 · 출석 · 업적 |
| 상점 | 상점 · 시즌 패스 · 꾸미기 |
| 소셜 | 친구 · 랭킹 · 우편함 |
| 시스템 | 설정 · 공지 · 고객지원 |

- 우측 상단 빠른 버튼: 우편함 · 퀘스트 (알림 배지) [제안]

### 1-3. 던전 HUD 버튼 [기획 + 제안]

- 자동 이동 토글 · **배속** · 가방 보기 · 일시정지(설정·포기)

## 2. 메뉴 지도

```
마을
├─ [하단 바] 캐릭터 ── 장비 · 세팅 슬롯 · 스탯 · 상세 능력치 · 보유 스킬
├─ [하단 바] 가방 ──── 가방 · 창고
├─ [하단 바] 성장 ──── 단련 · 트리 · 강화 · 펫
├─ [하단 바] 던전 ──── ACT 선택 → 던전 선택 → 입장
└─ [하단 바] ☰ 전체 메뉴
      ├─ 레이드 · PvP · 길드
      ├─ 도감 · 퀘스트(일일·주간) · 출석 · 업적
      ├─ 상점 · 시즌 패스 · 꾸미기
      ├─ 친구 · 랭킹 · 우편함
      └─ 설정 · 공지 · 고객지원

던전
├─ 전투 화면 (자동 전투 + 리듬 원 + 배속)
├─ 가방 보기 (정리 / 버리기 = 자동 판매)
├─ 일시정지 메뉴
├─ 층 결과창 → 계속 / 귀환
├─ 사망창 (사망 원인 요약) → 광고 회수 / 그대로 귀환
└─ 10층 보스 결과창 → 자동 귀환
```

## 3. 화면별 HUD

### 3-1. 마을 HUD
- 좌상단: 이름 · 레벨 · **총 전투력** [기획]
- 우상단: 골드 · 캐시 재화 [기획]
- 하단 메인 바 (1-1) · 우측 상단 빠른 버튼 [제안]
- 마을의 다른 유저 (이름·레벨·직업) [기획]
- 알림 배지: 새 아이템 · 단련 가능 · 펫 레벨업 가능 · 퀘스트 완료 · 우편 [제안]

### 3-2. 던전 HUD
- 좌상단: 생명력 · 보호막 · 자원, 레벨 [기획]
- 우상단: ACT · 던전 · **층 n/10** · **남은 몹** · 이번 층 전리품 수 · **가방 칸 사용량** [기획]
- 하단: 스킬 슬롯 [기획]
- 고정 위치: **리듬 원** (리듬 무기 장착 시) [기획]
- **배속**: ×1 / ×2 기본, ×3 은 [미정: 캐시·시즌 패스 혜택 여부] [기획 + 제안]

### 3-3. 던전 안 가방 [기획]
- 칸 격자 보기, 아이템 상세.
- **가방에서 꺼낸(버린) 아이템은 자동 판매**되어 골드가 됨.
- 장착 불가 (마을에서만).

### 3-4. 층 결과창 [기획]
- 처치 수 · 시간 · 경험치 · 획득 골드
- 전리품 목록 (등급·전투력·칸 크기·판매가), 가방 칸 미리보기
- **챙기지 못한 전리품은 자동 판매**
- 가방 속 아이템을 빼서 자리 만들기 (뺀 아이템도 자동 판매)
- 버튼: **계속 진행** · **마을 귀환** · 추천 선택
- **5초 자동 진행** (옵션)
- 경고: "계속 진행하다 쓰러지면 가방 아이템 절반 손실"

### 3-5. 사망창 [기획]
- **잃게 될 아이템**(절반) 미리 표시
- 버튼: **광고 보고 전부 회수** · 그대로 귀환
- **사망 원인 요약**
  - 받은 피해 **유형별 비율**: 물리 / 불 / 얼음 / 번개 / 대지 / 빛 / 어둠 (막대 그래프)
  - **몬스터별 받은 피해** 상위 목록: 몬스터 이름 · 피해량 · 비율 · 주 피해 유형
  - 회피·막기 실패 횟수, 마지막 일격
  - **취약 방어 힌트**: 비율 대비 낮은 저항·방어 항목 표시 (예: "불 피해 48% — 불 저항 12%")

### 3-6. 10층 보스 결과창 [기획]
- 던전 클리어 보상 · 다음 던전 개방 알림 · 전리품 선택 후 자동 귀환

## 4. 메뉴 상세

### A. 캐릭터

| 화면 | 구성 | 동작 |
| --- | --- | --- |
| 장비 [기획] | 9슬롯 + 캐릭터 미리보기, 아이템·전투력·부여 스킬 | 상세 / 해제 / 강화 바로가기 |
| 세팅 슬롯 [기획] | 탭 3개(최대 6), 세팅별 장비·전투력, **PvP 세팅** 표시 | 저장 / 불러오기 / 이름 변경 / PvP 세팅 지정 / 확장(캐시) |
| 스탯 [기획] | 힘·민첩·지능, 남은 포인트, 포인트당 효과 | 분배 / 재분배(저비용 골드) |
| 상세 능력치 [제안] | 공격·방어·속성 피해/저항·치명타·회피·쿨감 전체 | 보기 |
| 보유 스킬 [제안] | 장비가 부여한 스킬·등급·태그·보조 권능 적용 결과 | 보기 |

### B. 가방 / 창고 [기획]

- 가방(던전 휴대, 칸 제한)과 창고(마을 보관)를 한 화면에.
- 이동 · 장착 · 판매 · 강화 · 정리, 잠금(판매 방지) · 필터 · 일괄 판매(등급 이하) [제안].

### C. 성장

| 화면 | 구성 | 동작 |
| --- | --- | --- |
| 단련 [기획] | 공격·생명·방어·저항, 단계 / **ACT 한도**, 다음 비용 | 단련 / 연속 단련 |
| 트리 [기획] | 전체 지도, 보유·구매 가능·미개방 구분, **메커니즘 노드 강조** | 구매 / 경로 미리보기 / 초기화(저비용) / 가지 필터 |
| 강화 [기획] | 장비 선택 → 현재·다음 수치, 비용 | 강화 |
| 펫 [기획] | 펫 목록, 등급·레벨, 스킬(개방/잠김) | 동행 / 레벨업 / 등급업 |

### D. 던전 [기획]

- ACT 목록 → ACT별 던전 4~6개 (난이도 순).
- 던전 상세: 컨셉 · 몹 · 10층 보스 · **드랍 등급 상한** · 아이템 레벨 범위.
- 입장 전 확인: 가방 칸 사용량, 사용할 세팅 슬롯 [제안].

### E. 레이드 [기획]

- 보스 정보 · **참가 전투력 기준** · 오늘 남은 입장.
- **무작위 매칭** / **파티 만들기** (친구·길드원).
- 결과: 기여도 순위 · 보상.

### F. PvP [기획]

- 시즌 정보 (남은 기간, **등급·점수**), 대전(자동 전투), **PvP 세팅**, 랭킹, 기록.
- 보상: 시즌 보상(**캐시 재화 · 꾸미기**), 등급 도달 보상 [제안], 일일 대전 보상 [제안].

### G. 길드 [미정 — 오프라인으로 먼저 구성]

- 후보: 정보 · 멤버 · 출석/기부 · 길드 상점 · 길드 보스 · 길드전 · 채팅.

### H. 도감 [기획]

- 아이템(전설·세트·고유 권능) · 스킬(각성 효과) · 몬스터 · 보스, **미획득 미리보기**.
- 수집 보상 [제안].

### I. 퀘스트 · 출석 · 업적

#### 일일 퀘스트 [제안 — 게임 방향에 맞춘 구성]

매일 5개 (아래 풀에서 무작위), 전부 완료 시 보너스 상자.

| 분류 | 예시 | 의도 |
| --- | --- | --- |
| 반납 | **희귀 등급 장비 1개 반납**, 2×3칸 이상 장비 2개 반납, 불 속성 옵션 장비 1개 반납 | 가방 칸 선택에 의미 추가, "팔까 반납할까" 고민 |
| 처치 | 몬스터 300마리 처치, 정예 10마리, 던전 보스 1회 | 기본 사냥 동기 |
| 깊이 | 아무 던전 **7층 이상 도달**, 귀환 없이 5층 연속 클리어 | 위험 감수 보상 |
| 생존 | 한 판 동안 사망 없이 10층 클리어 | 빌드 완성도 확인 |
| 리듬 | 리듬 판정 성공 200회, 연속 성공 30회 | 리듬 빌드 유도 |
| 성장 | 단련 3회, 트리 노드 2개 구매, 강화 1회 | 골드 소모 순환 |
| 경제 | 판매로 골드 N 획득 | 폐지 = 돈 루프 |
| 콘텐츠 | PvP 3회, 레이드 1회 | 콘텐츠 순환 |

- 보상: 골드 · 소량 캐시 재화 · 장비 상자(현재 ACT 기준) [제안]
- 주간 퀘스트: 일일 묶음 확장판 (예: 반납 10회, 보스 7회) [제안]

#### 출석 [제안]

- **28일 주기 출석판**: 매일 골드·장비 상자, 7·14·21·28일째 캐시 재화·꾸미기.
- 신규 유저 **7일 출석**(별도): 초반 성장 지원 (세팅 슬롯 체험, 펫 등급업 재료 등).

#### 업적 [제안]

- 누적 기록형: 처치 수, ACT 개방, 전설 획득 수, 리듬 연속 성공, 도감 완성도. 보상은 칭호·꾸미기 위주.

### J. 상점 [제안 — 장르 일반 구성을 우리 방향에 맞춤]

| 상점 | 재화 | 판매 항목 |
| --- | --- | --- |
| 캐시 재화 상점 | 현금 | 캐시 재화 묶음, 첫 구매 보너스 |
| 패키지 | 현금 | 스타터 패키지, ACT 개방 기념 패키지, 월정액(매일 캐시 재화 지급 + 소소한 편의) |
| 시즌 패스 | 현금 | 무료/유료 2단 보상 트랙 (시즌 미션 진행), 보상: 골드·캐시 재화·꾸미기 |
| 편의 | 캐시 재화 | **세팅 슬롯 확장(최대 6)** [기획], 창고 확장, 배속 ×3 [미정] |
| 골드 상점 | 골드 | 매일 바뀌는 장비 몇 개(현재 ACT 기준, 옵션 고정), 스탯 재분배 |
| 꾸미기 | 캐시 재화 / PvP 보상 | 외형 · 스킬 이펙트 · 칭호 [기획] |

- 원칙 [제안]: **전투력을 직접 파는 상품은 지양**하고 편의·꾸미기·시간 단축 위주 (하드한 난이도와 빌드 재미를 지키기 위해).

### K. 소셜 · 시스템 [제안]

- 친구(레이드 초대), 랭킹(PvP·도감), 우편함, 공지, 고객지원.

## 7. 확인 결과 (v2 검토)

- 하단 메인 바 5개 구성 확정.
- 배속 ×3은 유료 혜택 (×1/×2 기본).
- 반납 퀘스트에 낸 장비는 사라지고 퀘스트 보상을 받음.
- 상점 원칙: 전투력 직접 판매 지양 확정.
- 캐시 재화 이름: **템포 (Tempo)**.
