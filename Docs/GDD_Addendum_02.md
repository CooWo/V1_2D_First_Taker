# GDD 추가 사항 02 — 층 결과창 · 칸 가방 · 사망 패널티 · 마을 · 던전 형태

2026-11-26 확정. `GDD_Addendum_01.md`의 "층당 반출 개수 / 포탈" 규칙을 아래로 **대체**합니다.

## 1. 층 클리어 → 슬로우 모션 → 결과창 (포탈·계단 없음)

- 마지막 몬스터를 잡는 순간 **슬로우 모션**(시간 0.25배, 약 2.4초)과 "층 정복!" 연출.
- 이어서 **결과창**: 처치 수 · 소요 시간 · 경험치 · 획득 장비, 가방 칸 미리보기.
- 결과창에서 플레이어가 결정: **다음 층 ▶ 계속** 또는 **마을로 귀환**. (자동 확정 없음)
- 코드: `Game/DungeonSession` (`FloorState.Clearing → Result`), 수치 `DungeonRules.ClearSlowMoSeconds / SlowMoScale`.

## 2. 칸 가방 (아이템별 크기)

- 가방 **8×5 = 40칸**, 마을 창고 **10×8 = 80칸**. 아이템은 모양만큼 칸을 차지(회전 없음, 빈 곳 자동 배치):

| 아이템 | 칸 |
| --- | --- |
| 반지 · 목걸이 | 1×1 |
| 성물 · 마법봉 · 마력원 | 1×2 |
| 한손검 · 화살통 | 1×3 |
| 지팡이 | 1×4 |
| 투구 · 신발 · 방패 · 격투 장갑 | 2×2 |
| 갑주 · 활 | 2×3 |
| 대검 | 2×4 |

- 층당 개수 제한은 없애고(옵션 `MaxPicksPerFloor`, 기본 0), **가방 칸이 곧 선택 압박**: 결과창에서 들어가는 것만 고르고 나머지는 자동 판매.
- 결과창에서 가방 속 장비를 팔아 자리를 만들 수 있음. 가방 메뉴의 "정리"로 빈 칸 모으기.
- 코드: `Items/Inventory`(격자), `Items/ItemShapes`, `Economy/FloorLoot`.

## 3. 계속할수록 위험 — 사망 패널티

- 계속 진행하다 쓰러지면 **가방 아이템의 절반(올림)을 무작위로 잃고**, 그 층 전리품도 잃은 채 **마을로 귀환**.
- 장착 장비와 창고는 안전.
- 코드: `Inventory.LoseHalf`, `DungeonSession.OnCombatantDied`.

## 4. 마을

- 앱 시작·귀환·사망·레이드 종료 시 마을로. 광장, 길, 건물이 있는 허브.
- **다른 캐릭터들**이 이름·레벨·직업 표시와 함께 돌아다님 (지금은 오프라인 시뮬레이션 7명, `ITownPresenceSource`를 온라인 구현으로 교체 예정).
- 마을 메뉴: 장비 · 가방 · **창고** · 트리 · 펫 · 레이드 · **던전 입장**(개방된 던전 선택, 1층부터).
- 던전 안 메뉴는 장비 · 가방만 (성장·보관은 마을에서).
- 각 던전의 5층(보스)을 깨면 다음 던전 개방.

## 5. 던전 형태 (광장형 탈피)

층마다 지도 생성기 6종 중 하나 (보스 층은 기둥 홀). 크기는 몬스터 수에 비례.

| 형태 | 특징 |
| --- | --- |
| 방과 복도 | 크기가 다른 방들을 복도로 연결 |
| 동굴 | 세포 자동자로 만든 울퉁불퉁한 동굴 |
| 십자 회랑 | 중앙 광장 + 네 갈래 끝 방 + 곁방 |
| 순환 회랑 | 사각 순환 통로 + 모서리 방 + 한쪽만 열린 성소 |
| 구불 회랑 | 지그재그 긴 통로와 중간 방들 |
| 기둥 홀 | 기둥이 늘어선 넓은 홀 (보스 층) |

- 벽 충돌(미끄러짐), 투사체는 벽에서 소멸, 시야가 막히면 공격하지 않음.
- 몬스터는 방에 무리로 배치되어 **대기**하다가 플레이어를 보거나 맞으면 추적. 보스는 가장 먼 방.
- 자동 사냥은 남은 적을 찾아 **길찾기**(BFS 거리장)로 벽을 돌아 탐색.
- 코드: `Dungeon/Layouts.cs`, `World/Navigation.cs`(`GridMap`, `GridNavigator`), `Dungeon/FloorSpawner`.

## 6. 캐릭터 크기

히어로시즈처럼 캐릭터가 화면에서 작게 보이도록 카메라 시야를 넓힘 (세로 반높이 7 → 10, 세로 화면 최소 반폭 5.5 → 7.5, `CameraFollow`).
